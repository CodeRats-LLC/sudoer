# Sudoer

**Own The Loop.** An Agentic Workflow Environment for Dev, Ops, and QA,
from [CodeRats](https://coderats.llc).

Sudoer is a native macOS workspace for working alongside AI: your
terminals, agents, flows and hosts in one place, running on compute
you own. This repository is where Sudoer is released — downloads,
release notes, docs, and issues. The source lives elsewhere.

> **Alpha.** Sudoer is early. Expect rough edges, and tell us about
> them — that is what this repository is for.

## Install

Apple silicon Mac.

```sh
curl -fsSL https://coderats.llc/install.sh | sh
```

Or download the `.dmg` from the
[latest release](https://github.com/CodeRats-LLC/sudoer/releases/latest).
Alpha builds are signed but not yet notarized by Apple: the first time
you open a downloaded copy, macOS asks you to allow it in **System
Settings → Privacy & Security → Open Anyway**. The install script and
in-app updates are not asked.

Sudoer updates itself: a new release is offered when you launch it,
or within the hour while it runs.
